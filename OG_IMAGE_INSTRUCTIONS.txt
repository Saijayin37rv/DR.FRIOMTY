INSTRUCCIONES: Generar imagen optimizada para `og:image` (recomendado 1200x630, JPG, calidad 80-85)

1) Usando ImageMagick (Windows - PowerShell / CMD):
magick convert instalacion_finalclima.jpg -resize 1200x630^ -gravity center -extent 1200x630 -strip -quality 85 assets/og-image.jpg

2) Usando Node.js + sharp (necesita `npm install sharp` o usar `npx`):
// guardar como build-og.js
const sharp = require('sharp');
sharp('instalacion_finalclima.jpg')
  .resize(1200, 630, {fit: 'cover', position: 'centre'})
  .jpeg({quality:85, mozjpeg:true})
  .toFile('assets/og-image.jpg')
  .then(()=> console.log('og-image.jpg creado'))
  .catch(err=> console.error(err));

3) Nombre recomendado del archivo final: assets/og-image.jpg
4) Generar la imagen automáticamente (Node.js + sharp):

  a) Desde la carpeta `WEB` ejecuta:

  ```bash
  npm install
  npm run build-og
  ```

  b) El script leerá `instalacion_finalclima.jpg` y escribirá `assets/og-image.jpg`.

5) Publicar en Netlify:

  - Confirma que `assets/og-image.jpg` está en el repo y commitea/pushea los cambios. Netlify desplegará automáticamente si tu sitio está conectado al repositorio.
  - Alternativa: sube manualmente la carpeta `assets` a Netlify mediante drag & drop en el panel de Sites → Deploys → Deploy site.

6) Actualiza en `index.html` las meta tags `og:image` y `twitter:image` con la URL absoluta de tu dominio:
  https://drfriomty.online/assets/og-image.jpg

7) Validación: usa el Debugger de Facebook (Sharing Debugger) y el Card Validator de Twitter para comprobar que la imagen se muestra correctamente.
